# 安全政策 / Security policy

提示词、项目数据和备份默认属于私人内容。请不要把真实提示词、用户数据库、备份、日志或本机路径附加到公开 Issue。安全问题请通过仓库的 **Security → Report a vulnerability** 私密入口报告。

Prompts, project data, and backups are private by default. Do not attach real prompts, user databases, backups, logs, or local paths to public issues. Report vulnerabilities privately through **Security → Report a vulnerability** in this repository.

当前维护版本为 `0.1.x`。请提供受影响版本、最小复现和脱敏证据；不要发送密码、Token、账号信息或其他秘密。

The currently maintained line is `0.1.x`. Include the affected version, a minimal reproduction, and redacted evidence—never passwords, tokens, account data, or other secrets.
