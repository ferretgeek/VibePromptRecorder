## 0.1.4 - 2026-07-31（审查闭环与安全加固版）

### 编辑、关闭与显示一致性

- 修复安全预览切回所见即所得和切换轮次后仍保持只读的问题；Markdown 安全分析增加短防抖，降低输入时全文克隆频率。
- 完成轮次改为保存循环追平最新输入后再锁定，慢保存期间继续输入不会丢失；并发完成请求继续合并。
- 正常关闭先执行 `wal_checkpoint(TRUNCATE)`，再以单调 generation 登记关闭意图；迟到的标记不能覆盖取消或强制退出。
- 字体加载完成后按已保存锚点重新测量虚拟时间线，避免字体切换后的卡片高度漂移。

### 数据、文件与安全边界

- 活动数据根在 Windows 上同时拒绝 UNC 和映射网络驱动器；WebView2 仅清理固定可再生缓存白名单，持久状态和未知文件保持不动。
- 已导入字体在启动暴露前校验大小与 SHA-256；系统字体同时枚举 32/64 位注册表视图，字体解析从停止维护的 `ttf-parser` 迁移到 Fontations `skrifa`。
- Markdown、项目包、完整备份和字体的本地读取选择移入 Rust 原生层，移除 renderer 文件对话框权限和未使用插件。
- 备份恢复增加项目、轮次、草稿、排序、时间、revision、视图引用和 FTS 原文一致性验证；损坏或伪造名称的自动备份不再阻断新备份。
- 移除无法可靠建立画布边界的远程 AVIF 支持；PNG、JPEG、GIF、WebP、BMP、ICO 继续经原生有界解析与 SSRF 防护加载。

### 依赖与发布

- 更新 `plist`/`quick-xml`、`time` 等通告涉及链路，移除 `tauri-plugin-dialog` 和 `ttf-parser` 直接依赖；Rust 最低版本调整为 1.89。
- 当前锁定的 SQLite 构建链路使用 Rust 1.95 稳定的 `cfg_select!`，公开源码的最低 Rust 版本与 CI 同步提升至 1.95。
- Rust 验证和便携打包在任何字体相关测试前固定执行 `prepare:tauri`，支持干净构建目录。
- 发行脚本不再保留历史 manifest，并在新版成功落盘后只清理明确匹配的旧版 ZIP、哈希和依赖清单。

## 0.1.3 - 2026-07-31（编辑体验修复版）

### 编辑器与操作

- 修复 Markdown 单换行在所见即所得模式中被显示成普通空格的问题；保留原文的同时按真实行距显示。
- Markdown 源码正文改用与所见即所得一致的正文字体、字号、字重和行高，代码块仍保留代码字体。
- 输入规则调整为 `Enter` 当前文本换行、`Ctrl+Enter` 开始新段落；所见即所得和源码模式行为一致。
- “完成并新建下一轮”只保留正文顶部一个按钮；单按 `Ctrl` 执行，任何 `Ctrl` 组合键都不会误触发。

### 界面与验证

- 删除时间线底部和详情头部的重复主按钮，工具栏只保留必要模式、换行说明和唯一主操作。
- 手机端重新组织模式选择与主按钮，不再裁切左侧模式；复制按钮并回标题行，减少无意义高度。
- 新增字体一致、单换行、换行/分段、单独 `Ctrl` 和三档响应式回归测试。

## 0.1.2 - 2026-07-30（生产级复核版）

### 数据一致性与恢复

- 备份恢复新增“取消已准备恢复”闭环：设置页会锁定待恢复状态，允许明确取消；取消失败保留状态并提供重试，启动仍会清理已提交流程遗留的临时目录。
- 最近删除中的恢复和永久删除会先等待当前编辑落盘，避免数据库结构变化与编辑缓冲交错；删除当前轮次后按邻接关系选择仍存在的轮次。
- 同一轮次从时间线进入详情时仍会持久化详情状态；轮次被删除时一并清理失效的时间线锚点。
- 所有会改变项目、轮次、设置、导入、恢复或字体状态的成功操作都会登记数据变更，并以 5 秒防抖触发自动备份检查；内容编辑会先确认最新序列已经落盘。

### Markdown、导入导出与 Windows 兼容

- 复制当前轮次时直接读取编辑器最新缓冲，不再复制数据库中的上一版；复制其他轮次仍以 Rust/SQLite 为事实来源。
- 可读 Markdown 导出不再制造只有包装头的空草稿；零正式轮次包装可正常识别；项目名、文件名、聚合索引标签与链接分别按 Markdown、URL 和 Windows 文件名规则安全编码。
- Windows 文件名长度按 UTF-16 单元截断，补齐保留设备名与控制字符处理；导出项目名中的换行、控制符不会破坏结构化头或索引。
- 纯复制模式保持原文字节不变，但在发现未闭合围栏代码块、原始 HTML 等拼接风险时先给出明确确认；不会为“修复”风险擅自改写内容。
- 达到 2 MiB 的安全预览改为最多 256 Ki UTF-16 单元的有界纯文本视图，并明确提示完整内容仍在编辑器中，避免在主线程构造超大 Markdown React 树。

### 交互、无障碍与发布

- 浏览器仓库补齐设置命令参数、字段级 patch、冲突保存、项目名规范和轮次编号语义，使隔离 E2E 与原生仓库行为保持一致。
- 嵌套弹窗只允许最上层拥有 `aria-modal`；被覆盖弹窗使用 `inert` 与 `aria-hidden`，焦点恢复到正确层级。
- 平板、窄窗口与 125%/150% 等效视口下，编辑器分段按钮不再挤压换行，非关键快捷提示会在空间不足时隐藏。
- 发布脚本将安装、Vitest、Playwright、Cargo、Tauri 构建统一限制为最多 2 个任务；浏览器 E2E 固定 1 worker，避免便携机打包时资源争用。
- 为 Milkdown 间接使用的 Vue `esm-bundler` 显式设置官方编译期标志：保留 Options API 兼容性，关闭生产 DevTools 与 hydration 详情，消除开发/E2E 告警并允许生产 tree-shaking。

### 本机验证

- 需求追踪 256 条、核心字体 10 文件、SQLite schema v2、Prettier、ESLint、TypeScript、Web 构建、Rustfmt 和 Clippy `-D warnings` 均通过。
- Vitest 21 个文件共 130 项通过；Rust 72 项通过、1 项手动性能入口按设计 ignored；手动后端压力样本为短搜索 50 ms、项目包 1,175 ms、Markdown 导出 451 ms、数据库快照 557 ms、完整备份 1,092 ms。
- 最终 Playwright 使用 1 worker 覆盖 `1440×900`、`768×1024`、`390×844`：19 项通过，23 项按视口/场景设计跳过，0 失败；100 KiB 保存 866 ms，2 MiB 加载 1,827 ms、保存 1,540 ms，1,000×100 时间线加载 1,068 ms、尾部定位 100 ms、DOM 卡片 6→5。
- 多台 Windows 实机、五档真实 DPI、真人微软拼音候选窗和物理缺失 WebView2 仍是外部验证项，不以本机等效测试冒充通过。

## 0.1.1 - 2026-07-29（个人自用成品）

### 数据安全与恢复

- 自动保存、切项目/轮次和安全关闭统一等待最新编辑序列真正落盘；冲突存在时暂停该轮后续自动保存，解决后再恢复。
- 设置协议改为带 `formatVersion` 的字段级 patch，拒绝未知字段；损坏设置先备份为 `settings.broken.*`，再使用安全默认值继续。
- 启动不再静默永久清理回收站；项目和轮次只在用户逐项确认后永久删除。所有活动轮次操作同时校验父项目仍存活。
- 结构撤销失败会恢复撤销项，清空草稿保留快照；备份恢复、迁移和 revision 冲突继续坚持“先恢复点、后替换”。
- 冲突恢复点增加数量和总容量上限；自动备份按归档 manifest 时间剪枝并始终保留最新可恢复快照。

### 编辑、状态与性能

- Markdown 安全分析迁入 Web Worker，行内数学识别改为线性扫描；Shiki 对超过 128 Ki UTF-16 单元的代码块完整转义为纯文本，避免高亮阻塞。
- WYSIWYG 依据 ProseMirror 真实 `docChanged` 事务识别编辑：初始化规范化不写回，菜单命令、拖拽和真实输入均会保存；原文字节保真与真实编辑均加入回归。
- 修复导航迟到响应、删除轮次 flush 竞态、连续设置写入回滚、搜索关闭破坏编辑器历史、冲突对话框后台保存和结构撤销并发问题。
- CodeMirror 自动换行使用 `Compartment` 动态重配；时间线按真实可见项翻页并恢复像素锚点，卡片回调稳定化，闲置导入字体从 `document.fonts` 卸载。
- 导入在数据库锁外完成解压、UTF-8、结构、大小和哈希校验；搜索、导出和备份使用独立只读连接或在线快照，避免长时间占用全局写锁。

### Windows、文件与发布

- 所有重 IO Tauri command 改为异步；导出目标由 Rust 原生保存对话框选择，移除渲染层任意输出路径能力。
- 数据根增加候选路径侧锁、UUID marker 临时文件、扩展 UNC 判定和严格孤儿清理；Windows 目录同步使用正确目录句柄。
- WebView2 按官方 Evergreen 注册表键检测；第二实例携带 `--data-dir` 时明确提示不会切换当前实例。
- 字体导入采用批次原子提交并在启动时对账登记、文件、大小和哈希；缺失字体安全降级，崩溃临时文件严格清理。
- 打包新增全局锁、最终 ZIP 重新解压复验、历史包自推版本校验、PE 路径脱敏，以及不伪造外部验收的 `PersonalUse` 成品通道。

### 最终本机验证

- `pnpm verify`：256 条需求追踪、字体/schema 审计、Prettier、ESLint、TypeScript、17 个 Vitest 文件共 102 项、Web 构建、Clippy `-D warnings`、66 项 Rust 测试和 Windows x64 Release 构建全部通过；另有 1 项手动性能入口按设计 ignored。

- 最终打包门禁实测：D1 100 KiB 保存 392 ms；D3 2 MiB 加载 1,774 ms、保存 1,437 ms；D2 1,000×100 加载 937 ms、尾部定位 79 ms、DOM 卡片 6→5。
- 0.1.1 原生 EXE 已用隔离数据目录完成启动、窗口出现、安全关闭与 clean-shutdown 冒烟；0.1.0 历史 ZIP 仍可通过新验证器完整复验。
- 个人自用成品可交付；真实五档 DPI、真人微软拼音、Win10/另一台 Win11 及 WebView2 物理缺失场景仍保持外部待验，不宣称公开分发验收完成。
