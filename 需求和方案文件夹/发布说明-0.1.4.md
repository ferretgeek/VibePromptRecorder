# 提示词记录工具 0.1.4 发布说明

发布日期：2026-07-31  
交付类型：Windows x64 个人自用便携版

## 本版变化

- 修复安全预览退出、切换轮次、慢保存期间完成轮次和 Markdown 分析频率问题，输入不会因提前锁定而丢失。
- 正常关闭前执行 WAL 截断，并用 generation 防止迟到 IPC 把强退误记为安全退出；字体加载后重新测量虚拟时间线。
- 活动数据根同时拒绝 UNC 与映射网络驱动器；WebView2 只清理固定可再生缓存，不触碰持久状态或未知文件。
- 启动时校验用户字体大小与 SHA-256；字体解析迁移到 Fontations，并同时枚举 Windows 32/64 位注册表视图。
- Markdown、项目包、完整备份和字体的读取选择移到 Rust 原生层，renderer 不再拥有文件打开权限。
- 备份恢复增加完整业务语义和 FTS 原文一致性验证；损坏或伪造名称的自动备份不会阻断新备份。
- 明确拒绝无法可靠建立画布边界的远程 AVIF；其他支持格式继续经有界解析和 SSRF 防护。
- 修复 RustSec 与前端依赖通告；发行脚本在新版成功后只保留当前 ZIP、哈希、依赖清单和 manifest。

## 兼容性与升级

- 数据库 schema：v2，未变化。
- 项目包与完整备份格式：v1，未变化。
- 0.1.3 的 206 个数据文件、12,383,441 字节在迁移前后逐文件大小与 SHA-256 一致；首次启动只清理了白名单内的三项 WebView2 可再生缓存。
- 迁移前数据完整备份：`成品文件夹/用户数据备份/upgrade-to-0.1.4-20260731-205212/`。
- 旧版 EXE、资源、ZIP、独立发布说明、验收报告和 manifest 均不保留；历史变化只在 `CHANGELOG.md` 中保留文字。
