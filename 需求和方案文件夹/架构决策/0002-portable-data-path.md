# ADR 0002：便携数据目录

- 状态：已接受
- 日期：2026-07-20
- 最后校准：2026-07-29（0.1.1 收尾复核通过）

## 决策

发布版默认在主 EXE 同目录创建带 `.vpr-data-root.json` 标记的 `data/`。SQLite、备份、恢复区、导入字体、日志、临时文件与 WebView2 用户目录全部位于该根目录。路径从 `current_exe()` 解析，不依赖工作目录。

启动前验证目录标记、可写性、本地卷属性和独占锁。开发与自动化测试允许通过受控 `--data-dir` 或 `VPR_DATA_DIR` 指向隔离目录。非空且没有有效标记的 `data/` 不会被认领。

## 回退条件

相邻目录不可写时由原生目录选择器获取新位置；写入失败进入只读保护并保留编辑缓冲，不显示虚假保存成功。

## 0.1.1 实施补充（2026-07-29）

- 数据根优先级为 `--data-dir` → `VPR_DATA_DIR` → EXE 相邻 `data/` → 当前 EXE 目录哈希对应的 locator → 原生目录选择器。
- 候选路径在写 marker 前使用 `%LOCALAPPDATA%\VibePromptRecorder\initialization-locks\` 侧锁；marker 临时名使用 UUID，只清理严格匹配的应用孤儿。活动根再使用 `instance.lock` 独占锁。
- UNC 与 `\\?\UNC\` 活动库路径明确拒绝；OneDrive、Dropbox 等已知同步目录只警告，不误称为一律拒绝。
- 第二实例携带新的 `--data-dir` 时明确说明不会切换当前实例。安全关闭只有在前端已完成 flush 且窗口确实销毁后才写 `.vpr-clean-shutdown`。
- 设置页数据目录迁移和“按住 Shift 重选”仍是未来目标，不作为 0.1.1 已实现能力；当前迁移方式以完整退出后移动便携目录或原生备用目录选择为准。
