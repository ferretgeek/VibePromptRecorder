# ADR 0001：Markdown 编辑内核

- 状态：已接受
- 日期：2026-07-20
- 最后校准：2026-07-29（0.1.1 收尾复核通过）

## 决策

Markdown 原文是唯一持久化真源。默认所见即所得模式使用 Milkdown Crepe，源码模式使用 CodeMirror 6，历史卡片使用 `react-markdown + remark-gfm + rehype-sanitize` 的只读渲染。禁用 AI、LaTeX、图片上传和远程协作能力。

进入所见即所得前执行能力预检；含不受支持扩展、复杂原始 HTML、畸形结构或超大内容时降级到安全预览与源码编辑。未发生编辑的模式切换直接复用原始 Markdown，不触发规范化写回。

## 回退条件

若金样测试发现 Milkdown 在无操作往返中改变正文语义、代码、链接、列表层级或表格数据，则该内容标记为 `source_only`；若常用语法整体无法满足门槛，则替换编辑内核后再发布。

## 0.1.1 实施补充（2026-07-29）

- WYSIWYG 写回以 ProseMirror 事务发生时是否已完成初始化及真实 `docChanged` 为依据，不再依赖 DOM `input`、点击或焦点事件猜测。初始化规范化不会落库，菜单命令、块操作和真实输入会落库。
- Markdown 安全分析在 Web Worker 中执行；行内数学识别使用线性扫描。达到 2 MiB 的轮次直接进入 `source_only`，不在主线程尝试富文本解析。
- Shiki 当前仍在主线程按需运行，但代码块超过 128 Ki UTF-16 单元时完整转义为纯文本并显示提示；并不宣称“Shiki 已在 Worker”。
- 当前能力预检属于保守启发式规则和金样回归，并非完整 AST 语义等价证明。Markdown 原文仍是唯一真源，解析或生命周期异常时停止写回并提供源码恢复路径。
