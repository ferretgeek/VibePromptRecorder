# 提示词记录工具 0.1.4

这是一个面向 Windows 10/11 x64 的本地离线提示词记录工具。它不接入模型 API、不生成回答、不需要账号，也不会上传项目、提示词或使用遥测。

> 文档校准：2026-07-31。当前交付为经过逐项审查修复、完整本机门禁、便携包校验和现有数据启动/退出复核的 **0.1.4 个人自用便携成品**。

## 开始使用

1. 将整个 `提示词记录工具-0.1.4-portable` 目录放在本机可写位置，不要直接在 ZIP 内运行。
2. 双击 `提示词记录工具.exe`。应用依赖系统已安装的 Microsoft Edge WebView2 Runtime；缺失时会显示原生中文提示，且不会静默联网安装。
3. 首次启动会在程序旁创建 `data/`。若程序目录不可写，应用会要求选择另一个本地目录，并在 `%LOCALAPPDATA%\VibePromptRecorder\locators\` 保存仅包含目标路径的定位文件。
4. 在当前草稿中输入 Markdown。普通内容停止输入约 300 毫秒后自动保存；超过 512 KiB 的轮次使用约 1 秒防抖。
5. 点击正文上方唯一的“完成并新建下一轮”，或单独按一下 `Ctrl`，当前非空草稿会成为正式轮次，并生成一个新的空草稿。

升级旧版时，应先完全退出旧程序并备份旧 `data/`，再替换 EXE、资源、许可和说明文件；**不要删除或覆盖 `data/`**。0.1.4 的数据库 schema 仍为 v2，项目包和完整备份格式仍为 v1。

## 关键操作

- `Ctrl+N`：新建项目
- `Ctrl+S`：立即保存
- `Enter`：在当前文本中换行
- `Ctrl+Enter`：开始一个新段落
- 单按 `Ctrl`：完成当前轮并新建下一轮
- `Ctrl+Shift+C`：复制当前轮 Markdown 原文
- `Ctrl+Shift+F`：搜索全部项目、备注、草稿和代码
- `Ctrl+E`：切换所见即所得与 Markdown 源码
- `Ctrl+,`：打开设置
- `Ctrl+Alt+T`：切换窗口始终置顶
- `F2`：重命名当前项目
- `F6` / `Shift+F6`：循环切换顶部、项目栏、时间线和详情区焦点
- `Alt+Home`：时间线回到顶部（编辑器内不会劫持文本操作）
- `Esc`：关闭当前最上层弹窗或菜单；冲突和关闭保护等必须处理的窗口不会被直接跳过

界面默认使用晴空蓝白，并提供珊瑚暖杏、湖水薄荷、莓果淡紫、曜石深灰和跟随系统主题。界面、正文、代码字体可独立设置；可导入 `.ttf`、`.otf`、`.woff`、`.woff2`，文件会先解析、校验和去重，再复制进当前数据目录。

窗口使用应用自绘标题栏。可拖动顶部的应用名称、项目名称或空白区域移动窗口，双击该区域切换最大化；右上角提供最小化、最大化/还原和安全关闭按钮。

## 数据目录

所有可写业务数据都位于当前数据目录：

```text
data/
├─ .vpr-data-root.json
├─ .vpr-clean-shutdown          # 仅在安全退出后存在，下一次启动时移除
├─ instance.lock
├─ database/app.sqlite3
├─ backups/auto/
├─ backups/manual/
├─ recovery/
├─ fonts/imported/
├─ logs/
├─ temp/
└─ webview2/
```

应用还可能在 `%LOCALAPPDATA%\VibePromptRecorder\` 写入不含提示词正文的 `locators/` 数据定位文件和 `initialization-locks/` 初始化侧锁。项目、轮次、设置和字体登记仍保存在所选便携数据目录。

不要把活动数据目录放在 UNC、映射网络驱动器、OneDrive、Dropbox 或其他实时同步目录中。UNC 和映射网络驱动器会被拒绝；已知同步目录会显示警告。需要跨设备迁移时，请完全退出应用后复制整个便携目录，或使用完整备份。

## 导入、导出与备份

- 可读导出：单项目 `.md` 或全部项目目录；结构化标记、字节长度和 SHA-256 完整时可无损再次导入。损坏的结构化包装会被拒绝。
- 项目包：`.vcpproject`，用于无损迁移单个项目；同 ID 导入时创建新 ID，不覆盖现有项目。
- 完整备份：`.vcpbackup`，包含在线 SQLite 一致性快照和用户字体。每日自动快照仅含数据库；每周自动完整备份与手动完整备份包含用户字体。
- 最近删除：项目和正式轮次不会在启动时自动永久清理；只有在“最近删除”中逐项确认后才会永久删除。
- 导出目标由 Rust 原生保存对话框选择，网页渲染层不能指定任意写入路径。

## 恢复与故障处理

在“设置 → 数据与备份”选择 `.vcpbackup` 后，应用会先校验版本、条目、路径、大小、SHA-256、SQLite 结构与业务语义，再创建当前数据的恢复前快照。恢复在下次启动、创建业务窗口前切换数据库和字体；中断时依据恢复状态自动继续或回滚。

保存失败时不要关闭程序：编辑器中的完整缓冲仍在内存。可以重试、复制缓冲或导出恢复 `.md`。若出现 revision 冲突，默认选择“保留两份”；数据库版留在原轮，本地版保存为相邻正式轮次。选择本地替换前会先创建恢复点，冲突处理完成前自动保存保持暂停。

设置 JSON 损坏或越界时，原始值会先备份为数据库中的 `settings.broken.*`，然后使用安全默认值继续；遇到未来版本的设置格式则拒绝降级覆盖。数据库或 schema 检查失败时不会创建空库覆盖现场，而是显示原生中文错误并退出。请保留整个 `data/` 后再从已校验备份恢复。

## 搬迁、升级与校验

先完全退出应用并确认任务管理器没有残留进程，再复制整个便携目录；不要只复制 EXE。首次交付 ZIP 不含 `data/`，运行后才创建。旧版升级到 0.1.4 时数据库 schema 仍为 v2，项目包和完整备份格式仍为 v1；升级前仍建议创建手动完整备份。

`checksums.sha256` 覆盖 EXE、核心字体、许可、构建状态和本说明。可在 PowerShell 中校验单个文件：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\提示词记录工具.exe'
```

ZIP 的整体哈希位于 ZIP 旁的同名 `.sha256` 文件，发布目录的 `release-manifest.json` 同时记录 ZIP、EXE 和 lockfile 哈希。个人版未做代码签名，Windows 可能显示“未知发布者”。

## 隐私与安全边界

数据库是本地明文 SQLite，不包含应用层加密；能读取便携目录的人也能读取提示词。请使用 Windows 账户权限、BitLocker 或其他磁盘加密保护设备。远程图片默认不请求，只有单次明确授权后才加载；为保证 DNS 固定与逐跳 SSRF 校验不被代理绕过，远程图片请求不使用系统代理，因此仅允许代理出网的网络可能无法加载图片。远程 AVIF 因当前缺少受信的有界解析器而明确拒绝。外部链接在调用系统默认程序前会确认。应用不扫描代码项目、终端历史或其他应用窗口，也不监听剪贴板。

字体完整许可随包位于 `LICENSES/fonts/`，依赖许可清单位于 `LICENSES/third-party-licenses.txt`。当前本机验证和仍待外部完成的验收见 `BUILD-STATUS.md`、`发布说明-0.1.4.md` 与 `验收报告-0.1.4.md`。
